# OpenAI adapter evidence and limits

The request/response contract was checked on 2026-11-03 against [OpenAI's Responses endpoint reference](https://developers.openai.com/api/reference/resources/responses/methods/create) and its published OpenAPI schema for `https://api.openai.com/v1/responses`. Model capabilities/default reasoning effort came from [the GPT-5.4 nano model reference](https://developers.openai.com/api/docs/models/gpt-5.4-nano). No numeric price or account access was assumed.

`fixtures/openai-completed.json` is a deliberately synthetic text response following the documented `output[].content[].output_text` and `usage` structure. The token values are fictional test inputs, not live usage. Tests assert a total of 150 remains 150 even when cached/reasoning subsets are present. Missing counts are unavailable, not zero. Incomplete outputs and unexpected tool-call output are handled explicitly; no tool dispatch exists.

`src/ai.rs` starts ephemeral loopback HTTP servers in tests and runs the actual reqwest client/JSON request path against them. Each server inspects the request method/path, fake Authorization header, `store:false` and output cap, then returns a fixture status/body. Scenarios exercised: 200 text success, 401 authentication failure, 429 quota/rate limit, 500 service failure, 302 redirect refusal, malformed JSON and a delayed response exceeding the test client's 250 ms timeout. The timeout is observed by the caller and reports uncertain completion rather than claiming zero cost. These tests use only a hardcoded non-secret fixture key. The test endpoint override is private to the test module; the application endpoint is fixed to OpenAI HTTPS.

The installed Postman CLI is 1.7.1 and exposes neither `status` nor `simulation`; the API Simulation workflow could not run on that version. No CLI upgrade, login, workspace discovery, mock publication or deployment was performed. Stand-ins were built directly from the official contract and exercised locally instead. No provider-owned mock was retrieved.

Additional tests verify 3-pair/12,000-byte eviction, output-cap validation, request bodies containing no key, AI-off startup, local commands bypassing AI even with a dummy session key, public settings excluding the key, and disable clearing session state. Native synthetic checks verify displayed usage/cost labels and that system TTS receives only answer text.

This establishes local serialization, parsing, routing, limits, rendering and failure behavior against fixtures. It does not establish real model access, current account billing, network/TLS reachability to OpenAI, response latency, actual token counts, or live answer quality. **No credential was retrieved or entered, and no paid OpenAI API request was sent.** Live verification requires Dan's further approval and user-controlled session setup.

The later Keychain persistence adapter adds fake-store tests for explicit save/replacement/removal, read suppression, startup opt-in, denied storage and non-secret preference failures, plus actual temporary-file settings roundtrip/mode/corruption checks. Native policy tests inspect exact service/account, generic-password class, data-protection Keychain selection, synchronization off, no access-group override, noninteractive LAContext, and WhenUnlockedThisDeviceOnly accessibility without calling SecItem APIs. No real Keychain roundtrip is claimed; the UI was verified with `--no-keychain-restore` and no credential entry.

After the user hit OSStatus -34018, the backend was changed explicitly to the encrypted macOS default file-based Keychain for ad-hoc-build compatibility. Native policy checks now verify that data-protection/access-group/synchronization/accessibility attributes are absent or disabled and the default caller-only ACL is left intact. The original policy above describes the superseded backend. New fake-store tests establish that a valid typed key enables session use even when optional saving fails, while missing saved keys do not produce false enable success. No real Keychain item or API call is used in those tests.
